# Lovable design critique starter prompts

## Audit first (no edits)
> Activate Design Critic. Inspect the current page at 1440px desktop and 390px mobile, plus intermediate sizes where available. Do not edit yet. Give a concise evidence-based UX review using P0–P3, top three changes, and explicit untested assumptions. Preserve the existing brand.

## Fix the highest-impact issues
> Using the latest Design Critic review, implement the three highest-impact fixes only. Avoid unrelated refactors, new dependencies, or brand changes. Re-review the changed elements at 390px, 768px, 1024px and 1440px where possible and report pass/fail per issue.

## Compare alternatives
> Create three distinct design directions for this specific page. Vary information composition, type hierarchy, imagery, and color strategy, not just the accent color. Explain tradeoffs against the existing brand and target task. Do not merge directions until I select one.

## Animation review
> Review motion and micro-interactions. Explain what each movement communicates, remove gratuitous animation, add only a few meaningful moments, and verify mobile and prefers-reduced-motion. Do not claim to have tested motion you did not actually observe.

## Mobile-first critique
> Critique mobile as the primary experience. Check first-screen focus, navigation, form affordances, tap targets, 16px form inputs where relevant, horizontal overflow, spacing, loading/empty/error states, and reduced motion. Give exact fixes tied to the observed UI.
