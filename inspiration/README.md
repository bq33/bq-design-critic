# Design inspiration library

This folder contains credited references that help agents escape generic AI-generated aesthetics while preserving clarity, original branding and accessible interaction.

## Collections

- [Mia AI Lab — 76 HTML studies](mia-ai-lab-fable-5.2.md): links to all live demos and creator's original prompts, with twenty curated pattern notes.
- [Machine-readable Mia catalog](mia-ai-lab-fable-5.2.json): IDs, titles, URLs, highlights, tags, applications and cautions for use by code agents.

## Selection process

1. Identify page purpose, user task, constraints and existing brand.
2. Pick one composition idea, one interaction idea, and optionally one motion treatment, each with a clear job.
3. Explain why those patterns help this specific product and what to leave out.
4. Build independently; do not lift copyrighted code, images, screenshots, text or distinctive brand assets.
5. Recheck mobile, accessibility, readability, interaction and reduced motion.

**Inspiration is not evidence for a design score.** The source collection contains experimental HTML art; an agent should not infer production quality or usability certification from a pretty demo.
